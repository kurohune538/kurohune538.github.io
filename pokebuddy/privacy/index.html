Web版の利用状況の分析（Google アナリティクス 4）

Web版では、ネイティブアプリと同じGoogle アナリティクス 4（以下「GA4」）のプロパティに、Web用のデータストリームとして次の情報を送信します（gtag.js）。

  • 表示した画面の名前（URL、URLのクエリ、デッキやカードのIDは含めません）
  • 操作のイベント（ネイティブアプリと同じイベント名で送信します）
  • 内部ユーザーID（ランダムに生成されたUUIDです。名前やメールアドレスは送信しません）

  • ブラウザ・OSの種類、IPアドレスから推定されるおおよその地域など、GA4が自動的に収集する情報

検索語、デッキ名、カード名、メモ、対戦ログは送信しません。GA4はcookie（_gaなど）を使用します。

欧州経済領域（EEA。EU加盟国を含みます）、英国およびスイスからのアクセスでは、同意バナーで許可されるまでGA4を読み込みません（オプトイン）。それ以外の地域からのアクセスでは既定で有効とし、設定画面からいつでも無効にできます（オプトアウト）。同意した場合も、設定画面からいつでも無効にできます。アクセス元の地域は当方のサーバーがIPアドレスから判定し、判定できない場合は同意を求めます。選択の内容はブラウザのlocalStorageに保存します。

GA4で収集された情報は、Googleのプライバシーポリシーに従って取り扱われます。Googleによる情報の利用については、Googleのサービスを使用するサイトやアプリから収集した情報のGoogleによる使用をご覧ください。

Web版のエラー送信（Sentry）

Web版で予期しないエラーが発生した場合、エラーの内容、発生した画面の名前、本サービスのバージョン、ブラウザとOSの種類をSentry（Functional Software, Inc.）へ送信します。この送信にcookieは使用せず、IPアドレスはSentryに保存しない設定にしています。メールアドレス、検索語、デッキ名、URLのクエリは送信前に取り除きます。エラーの送信は、本サービスを安定して運用するという当方の正当な利益に基づき、同意を求めずに常に行います（設定から停止することはできません）。

カメラや写真ライブラリには、デッキコードの読み取り、カード・デッキの取り込み、 画像設定など、利用者が該当機能を操作した場合にのみアクセスします。取り込み用画像は原則として 端末内で処理されます。プロフィール画像等は、利用者が保存操作を行った場合に限りクラウドへ アップロードされることがあります。

In this Policy, “web app” refers to both the browser version and the Windows app. Information related to obtaining and downloading the Windows app from the Microsoft Store is handled under the Microsoft Privacy Statement.

2. Information We Collect

Account and profile information

  • An anonymous or registered account user ID.
  • Email address and authentication provider information.
  • Display name and profile image supplied when linking Google or Apple.

Content and activity you provide

  • Decks, card lists, deck version history, collections, adjustment cards, and related metadata.
  • Optional details you record for each owned card, such as condition, finish, grading information, acquisition price and currency, acquisition date, personal valuation and its currency, and notes.
  • Match results, opponent deck types, notes, battle logs, and usage history.
  • Replay data automatically sent from successfully completed two-deck solo games played without free moves or Undo, including card-ID deck lists, initial setup, actions and choices, outcome, end reason, turn count, random seed, rules/card-data version, and Service version.
  • Service preferences, notification read status, and card-data reports.
  • Profile images or other images you explicitly choose to upload.

Solo-game replay data does not include deck names, display names, profile information, human-readable battle logs, or device information. It is stored with an internal user ID only to enforce submission limits, delete the data when the account is deleted, and match bug reports you send with the games they refer to.

Device, browser, and diagnostic information

  • Device or browser type, operating system, Service version, language, and network type.
  • Country or approximate region inferred from an IP address.
  • When those features are enabled in a native app, Firebase installation identifiers (for Analytics), and crash and error data, performance data, network URLs, and response timing processed by Sentry.
  • Push notification token and platform when notifications are enabled.

Browser storage and access logs

  • The web app stores sign-in sessions, the return path used after OAuth, preferences, cross-tab sign-out synchronization, caches used to display card data and other content more quickly, and your analytics choice in browser storage such as local storage, session storage, and IndexedDB.
  • When analytics is enabled, Google Analytics 4 stores identifiers in cookies (such as _ga).
  • When you access the web app, the hosting infrastructure may process access logs such as IP address, approximate location derived from the IP address, browser and device information, access time, requested URL, and response status.

We use this browser storage to provide and secure the Services, remember preferences, synchronize state, display content, and, where enabled, analyze usage. We do not use it to serve ads or to track you for advertising. The web app does not enable Google AdMob (ads).

Usage analytics in the web app (Google Analytics 4)

The web app sends the following information, using gtag.js, to the same Google Analytics 4 (“GA4”) property used by the native apps, as a web data stream:

  • Names of the screens you view (not URLs, URL query strings, or deck or card IDs).
  • Events for actions you take, using the same event names as the native apps.
  • Your internal user ID (a randomly generated UUID). We do not send your name or email address.
  • The type of client: the Windows app, an installed PWA, or a browser.
  • Information GA4 collects automatically, such as browser and operating system type and approximate location inferred from your IP address.

We do not send search terms, deck names, card names, notes, or battle logs. GA4 uses cookies (such as _ga).

For access from the European Economic Area (EEA, including the EU member states), the United Kingdom, and Switzerland, GA4 is not loaded until you allow it in the consent banner (opt-in). For access from other regions, analytics is enabled by default and can be turned off at any time in Settings (opt-out). If you have given consent, you can also turn analytics off at any time in Settings. Our server determines your region from your IP address; if the region cannot be determined, we ask for your consent. Your choice is stored in your browser’s localStorage.

Information collected by GA4 is handled under Google’s Privacy Policy. To learn how Google uses this information, see How Google uses information from sites or apps that use our services.

Error reporting in the web app (Sentry)

If an unexpected error occurs in the web app, we send the error details, the name of the screen where it occurred, the Service version, and the browser and operating system type to Sentry (Functional Software, Inc.). This reporting does not use cookies, and Sentry is configured not to store IP addresses. Email addresses, search terms, deck names, and URL query strings are removed before sending. Error reporting is always on and does not ask for consent; it is based on our legitimate interest in operating the Services reliably and cannot be turned off in Settings.

Advertising information (when ads are enabled in a native app)

  • Advertising ID, App Set ID, IP address, product interactions, and diagnostic information processed by the Google Mobile Ads SDK.
  • Advertising consent status and non-personalized advertising preference.

Camera and photos

The Services access the camera or photo library only when you use a relevant feature, such as scanning a deck code, importing cards or decks, or choosing an image. Import images are generally processed on your device. A profile image or similar content may be uploaded to cloud storage only after you choose to save it.

  • Provide authentication, synchronization, backup, and core functionality of the Services.

  • Investigate possible improvements to AI battle features using automatically sent solo-game replay data that meets our collection criteria. We do not adopt a change based on this data alone; safety and performance are checked in separate evaluation battles.
  • Investigate bug reports you send by replaying your solo-game replay data.
  • Analyze usage to improve the Services (Google Analytics for Firebase in the native apps and GA4 in the web app).
  • Display ads, manage consent, measure advertising, and prevent fraud when advertising is enabled in a native app.

A deck matchup is shown only when it has at least 5 games from at least 3 users, and individual records, user IDs, and display names are never shown.
